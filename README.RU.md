#
Socker Ball Run - это проект на Unity 3D, использующий бесплатные ассеты и AI-генерированные спрайты. Основная механика проекта - управление мячом, катящимся по полю, уклоняясь от игроков противника и препятствий, прокладывая путь к воротам противника и забивая гол.

Внешние ассеты расположены в:  
```
./Assets/Import/AdditivePacks
```
## Содержание проекта на данный момент:

- ⚽ Механика движения мяча с постепенной остановкой.
- 🧑 Игроки-бустеры, игроки противника, метающие игроки.
- 🥅 Механика забивания голов.
- 🤖 Бот-вратарь.
- 🏪 Смена скинов мяча.
- 🏪 Магазин скинов мяча.
- 🏞️ 4 различных локации: футбольное поле, город, пустыня, острова.
- 🏆 Механика победы и поражения, подсчет очков за победу и поражение.
- 🌟 Обучение.
- 🏃‍♂️ Анимации игроков.
- 💥 Эффекты при попадании мяча в ворота.
- 📹 Анимация начала игры.
- 🏞️ 50 различных уровней.

## Сцены

Проект включает две основные сцены:
- **Главное меню** - запускает обработчики событий и содержит кнопки выбора уровня, магазин скинов.
- **Дополнительный внутриигровой UI** - динамически загружаемый интерфейс внутри уровня.
- **Уровни** - основные игровые сцены.

## Настройки Canvas

- Каждый **Canvas** должен иметь эталонное разрешение **1080x1920**.
- Большие текстуры не должны превышать **5MB** и должны быть предварительно сжаты в графическом редакторе.
- Формат текстур: **.png**
